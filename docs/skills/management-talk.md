# Management Talk (from 9arm-skills)

Rewrite engineering content for leadership (VPs, Directors, PMs).

## Audience
- Product/Framework names OK.
- JIRA keys / PR numbers OK.
- Concepts (race, sync, buffer) OK.
- **NO** function names, file paths, or line numbers.

## Channel Shapes
- **JIRA/Report**: Full structured block (Status, Impact, What broke, Next steps).
- **Slack**: Bolded TL;DR + 2-4 bullets. Under 80 words.
- **Standup**: 1-3 lines. Pattern: "<state> <thing>. <owner>. <next>."
- **Email**: Subject is TL;DR noun phrase. Flowing paragraphs.
